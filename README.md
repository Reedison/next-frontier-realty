# Next Frontier Realty Website

Static, responsive investment real estate website serving Greater Austin, Texas. Features commercial investment advisory, 1031 exchange and NNN property information, Austin area markets, investor calculators, and contact inquiry via email.

## Deployment
Deploy the repository root as a static site on Vercel. Framework preset: Other. Build command: none; output directory: repository root.

## Before public launch
Verify business contact information and brokerage licensing. Replace the temporary externally hosted logo and portrait with the approved original assets from the project ZIP. Link directly to current required Texas IABS and Consumer Protection Notice disclosures. Confirm licensed rights for photography. The inquiry form opens a visitor's email application; it does not store leads or connect to a CRM.

No historical transaction totals, closings, or track record claims appear on this version.
